## 🚀 Deployment (GitHub Pages)

The repository is named `andrewsgodwin-eng.github.io`, so GitHub Pages serves the `main` branch root at **https://andrewsgodwin-eng.github.io**.

Manual steps if Pages needs configuring:

1. Repository → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / Directory: `/ (root)` → **Save**
